# 指南文档

> 用于辅助开发的一些命令

## 环境检查

```bash
git --version
uv --version
docker --version
docker compose version
docker info
```

## Git

- 初始化 git 版本管理

```bash
git init
```

- 新建分支

```bash
git branch feat/dev
```

- 切换分支

```bash
git switch feat/dev
```

## Python

```bash
uv python install 3.12
uv init --bare --python 3.12 backend
Set-Location backend
uv python pin 3.12
uv add fastapi "uvicorn[standard]" "pydantic>=2,<3" pydantic-settings
uv add --dev pytest httpx ruff mypy
uv run python --version
```

## 后端启动

```bash
Set-Location backend
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## Docker

```bash
docker compose --env-file ./backend/.env -f ./backend/deploy/compose.yaml up -d
docker compose --env-file ./backend/.env -f ./backend/deploy/compose.yaml ps
docker compose --env-file ./backend/.env -f ./backend/deploy/compose.yaml logs postgres
```

## 检查测试

```bash
Set-Location backend
uv run ruff check --fix app tests
uv run ruff format app tests
uv run ruff format --check app tests
uv run mypy app
uv run python -m pytest -q
```
